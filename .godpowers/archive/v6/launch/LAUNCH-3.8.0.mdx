## Release Surface Copy

### Hero

**Scriveno checks provenance without rewriting your Voice DNA.**

Audit and clean delivery files locally by default. Get normalized Markdown, JSON, or SARIF reports, dry-run-first changes, and explicit outcomes for findings, degraded coverage, unsafe input, and provider failure.

Primary action: install `scriveno@3.8.0` from npm.

### What 3.8.0 Adds

- Audit one file or a bounded batch across text, web, raster, PDF, Office, ODT, and EPUB formats.
- Keep processing local unless the optional watermarks-remover provider is explicitly selected.
- Preview every clean before writing, publish a checked adjacent copy by default, and require confirmation plus backup for in-place work.
- Use exit codes `0`, `1`, `2`, `64`, and `70` in automation without parsing human prose.

### Why Scriveno Is Different

Scriveno treats provenance hygiene as file preparation, not an authorship verdict. It does not rewrite prose for detectors, request pixel removal, or treat stylometry as authoritative. Provider cleaning must match the exact locally proven safe result, while protected prose, pixels, frames, navigation, accessibility data, and disclosure history remain outside the mutation boundary.

Substitution test: replacing Scriveno with another writing CLI breaks the Voice DNA boundary, exact provenance exit contract, and locally proven provider-result requirement. The headline and differentiator are specific to this release.
