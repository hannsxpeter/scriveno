# Provenance Hygiene Feature Plan

## Delivery Strategy

Implement three vertical slices. Each slice starts with a failing focused test, adds the smallest source changes that satisfy it, then runs targeted verification before the next slice.

## Slice 1: Native Command Surface

Status: complete

### Requirements

P-MUST-01 through P-MUST-12, P-MUST-14 through P-MUST-16, P-MUST-18.

### Files

- Add `test/provenance-hygiene.test.js`.
- Add `commands/scr/provenance-check.md`.
- Add `commands/scr/provenance-clean.md`.
- Update `data/CONSTRAINTS.json`.
- Update `docs/command-reference.md`.
- Update `commands/scr/help.md`.

### Test First

1. Assert both command files exist with frontmatter, usage, response contracts, and automation status blocks.
2. Assert the audit is read-only and the cleaner is dry-run by default.
3. Assert cleaned-copy naming, explicit in-place gates, before and after verification, binary routing, confidence labels, optional-tool detection, and degraded results.
4. Assert statistical rewriting is not automatic and routes to Voice DNA commands without detector targets.
5. Assert both commands are registered, available for all work types, and discoverable through publish and repair surfaces.
6. Assert command reference entries and the headline command count match the live tree.

### Implementation

1. Write the read-only provenance audit contract.
2. Write the separate cleaning contract with safe output and confirmation behavior.
3. Register both commands and add them to command intents or families.
4. Document both commands in the canonical command reference.
5. Add them to compact help routing.

### Verify

```bash

```

## Completion Gate

- Both commands are installed through the existing file-backed runtime pipeline.
- Default behavior is non-mutating.
- Applied cleaning creates verified copies unless the writer explicitly confirms in-place operation.
- Reports distinguish confirmed evidence from uncertain or unsupported signals.
- Voice DNA and disclosure truth are unchanged.
- Targeted tests, the full suite, policy checks, and package dry-run pass.
